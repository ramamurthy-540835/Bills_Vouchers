# Portal module scope

Registration, amendments, cancellation/revocation, notices, certificates,
government ledgers, challans/payments, refunds, appeals, e-invoicing and e-way
bills are REFERENCE_ONLY in this release.

Canonical invoices, nine reports and internal working papers are local
application functions. Supported GSTR-2B import is IMPORT_RECONCILIATION.
No internal status is represented as a government acknowledgement, IMS action,
tax payment, portal verification or filed return.

Authorized API integration and government submission require a selected provider,
consent, verified schema and independently accepted acknowledgement flow.
