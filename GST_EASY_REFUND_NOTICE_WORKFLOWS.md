# Refund and notice scope

Refund categories include exports, SEZ, inverted duty, excess cash, deemed exports
and other legally eligible cases. Notice families include REG, ASMT, DRC, RFD and
APL. Applicability, evidence, deadlines and authorized representation require
scenario-specific review.

Required workflow: case intake → evidence → calculation/legal review → approval →
authorized submission where supported → official status/acknowledgement → archive.
These are REFERENCE_ONLY requirements; no live refund, notice response or appeal
submission is enabled in the current implementation.
