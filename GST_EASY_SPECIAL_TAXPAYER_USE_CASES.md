# Special taxpayer review

The workbook covers regular, composition, QRMP, manufacturing, trading, services,
exports/SEZ/imports, RCM, e-commerce, TDS, ISD, non-resident, OIDAR, UIN and multiple
GST registrations. Eligibility, registration dates, cancellation, jurisdiction,
signatory and obligations must be tied to the actual registration.

Reference-only forms must not appear as working filing actions. Each scenario
requires applicable evidence and independent expected calculations before formal
acceptance. All 50 scenario legal-review statuses remain pending.
